This project idea was gotten from a public GitHub Repository: 
- https://github.com/practical-tutorials/project-based-learning#python

It's a simple Gender classifier based on height, weight and shoe size. 

Doing this simple project taught me that a Decision Tree is a prediction system structure for machine learning models where it creates splits in a data set and tries to answer questions till it arrives at a prediction – I like to think of it like a flowchart. 

Other important things i used in this project were the: 

*DecisionTreeClassifier()* which is a decision-tree ML model specifically designed to classify data into categories, which is useful in this simple gender classification project,

*.fit(x,y)*: which basically says train the decision tree using x features and y labels so that it can figure out the relationship between them, and 

*.predict()*: which in this case, is used to predict the category of a particular set of features.
